# Finished Controllable Agent Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep controllable (channel/MCP-connected) agents visible on the dashboard as a dismissable "finished" card after their process exits, so a finished result never has to be hunted for in the Sessions list.

**Architecture:** The agent roster is gated on live processes, but channel discovery files (`~/.claude/dashboard-channel/{pid}.json`) survive process exit. The merger keeps an in-memory `seenLive` snapshot of channel-connected agents observed live this run; each tick it emits a synthetic `status: finished` agent for any seen PID that is no longer live but whose discovery file still exists, reconstructing the card from the cached JSONL path via `parser.ParseSessionFile`. A new `DELETE /api/agents/{pid}/channel` removes the discovery file (durable dismissal + fixes the existing leak). The frontend renders a finished badge + X on the card.

**Tech Stack:** Go 1.26 (merger, chi handlers, ent), Vue 3 + TS (Vite, Vitest), tygo (Go→TS type gen via `task generate`).

**Spec:** `docs/superpowers/specs/2026-06-21-finished-agent-cards-design.md`

package merger

import (
	"path/filepath"
	"sync"
	"time"

	"github.com/lx-wnk/agent-dashboard/sdk"
	"github.com/lx-wnk/agent-dashboard/server/internal/parser"
)

// liveSnapshot is the minimum identity needed to rebuild a finished agent card
// from disk after its process exits. Captured while the agent is live.
type liveSnapshot struct {
	sessionID   string
	path        string // resolved JSONL path; re-parsed for fresh cost/output
	projectPath string
	configDir   string
	provider    sdk.Provider
}

// staleTracker remembers channel-connected agents seen live during this server
// run and, once their process is gone, emits them as finished agents until the
// discovery file is removed (dismissal). All state is in-memory and process-
// scoped: a restart forgets finished cards (still in the Sessions list).
type staleTracker struct {
	mu   sync.Mutex
	seen map[int]liveSnapshot

	// channelFn reports whether a discovery file still exists for pid.
	// parseFn re-parses a JSONL path into session data.
	// Both are fields for testability; defaults wire to the real implementations.
	channelFn func(pid int) bool
	parseFn   func(path string) (*parser.SessionData, error)
}

func newStaleTracker() *staleTracker {
	return &staleTracker{
		seen:      make(map[int]liveSnapshot),
		channelFn: func(pid int) bool { avail, _ := channelDiscovery(pid); return avail },
		parseFn:   parser.ParseSessionFile,
	}
}

// record stores (or refreshes) the snapshot for a live agent. Called for every
// resolved live agent; non-channel agents are filtered later in buildStale
// because their discovery file never exists.
func (t *staleTracker) record(pid int, snap liveSnapshot) {
	if snap.sessionID == "" || snap.path == "" {
		return
	}
	t.mu.Lock()
	t.seen[pid] = snap
	t.mu.Unlock()
}

// buildStale returns finished agents for every seen pid that is no longer live
// and still has a discovery file. PIDs whose discovery file is gone are
// forgotten (dismissed or never channel-connected).
func (t *staleTracker) buildStale(livePIDs map[int]bool, baselineCost float64) []sdk.Agent {
	t.mu.Lock()
	defer t.mu.Unlock()

	var out []sdk.Agent
	for pid, snap := range t.seen {
		if livePIDs[pid] {
			continue // still running; the live path emits it
		}
		if !t.channelFn(pid) {
			delete(t.seen, pid) // discovery file gone → forget
			continue
		}
		session, err := t.parseFn(snap.path)
		if err != nil || session == nil || session.SessionID == "" {
			continue // unreadable session; emit nothing this tick
		}
		out = append(out, t.buildFinishedAgent(pid, snap, session, baselineCost))
	}
	return out
}

func (t *staleTracker) buildFinishedAgent(pid int, snap liveSnapshot, session *parser.SessionData, baselineCost float64) sdk.Agent {
	provider := snap.provider
	if provider == "" {
		provider = sdk.ProviderClaude
	}
	c := EstimateCostForProvider(provider, session.TokenUsage, session.Model)
	health := ComputeHealthScore(session, c.Total, c.Unknown, baselineCost)

	return sdk.Agent{
		PID:                       pid,
		SessionID:                 session.SessionID,
		Provider:                  provider,
		ProjectPath:               snap.projectPath,
		ProjectName:               filepath.Base(snap.projectPath),
		CWD:                       snap.projectPath,
		ClaudeConfigDir:           snap.configDir,
		Entrypoint:                session.Entrypoint,
		Status:                    sdk.AgentStatusFinished,
		ChannelAvailable:          true,
		LiveInjectable:            false,
		LastActivity:              session.LastActivity.Format(time.RFC3339),
		CurrentAction:             strPtr(session.CurrentAction),
		LastTools:                 append(make([]string, 0), session.LastTools...),
		Tasks:                     append(make([]sdk.TaskInfo, 0), session.Tasks...),
		Subagents:                 buildSubagents(session),
		TokenUsage:                session.TokenUsage,
		CostEstimate:              c.Total,
		CacheCreationCostEstimate: c.CacheCreate,
		CacheReadCostEstimate:     c.CacheRead,
		CostUnknown:               c.Unknown,
		HealthScore:               health,
		Model:                     strPtr(session.Model),
		ConversationTurns:         session.ConversationTurns,
		ToolCounts:                session.ToolCounts,
		Meta:                      session.Meta,
		LastOutput:                strPtr(session.LastOutput),
		LastBtw:                   session.LastBtw,
	}
}
```

package agents

import (
	"net/http"
	"os"
	"path/filepath"
	"strconv"
	"syscall"

	"github.com/lx-wnk/agent-dashboard/server/internal/channelconfig"
)

// DismissChannel handles DELETE /api/agents/{pid}/channel. It removes the
// dashboard-channel discovery files for a FINISHED agent so its card stops
// appearing on the dashboard. It refuses to act on a live PID (only finished
// agents are dismissable) and is idempotent when the files are already gone.
func (h *SpawnHandler) DismissChannel(w http.ResponseWriter, r *http.Request) {
	pid, err := strconv.Atoi(r.PathValue("pid"))
	if err != nil || pid <= 0 {
		http.Error(w, `{"error":"invalid pid"}`, http.StatusBadRequest)
		return
	}

	if processAlive(pid) {
		http.Error(w, `{"error":"agent is still running"}`, http.StatusConflict)
		return
	}

	home, err := os.UserHomeDir()
	if err != nil {
		http.Error(w, `{"error":"cannot resolve home"}`, http.StatusInternalServerError)
		return
	}
	base := filepath.Join(home, channelconfig.DiscoveryDir, strconv.Itoa(pid))
	for _, suffix := range []string{".json", ".pty.json"} {
		if err := os.Remove(base + suffix); err != nil && !os.IsNotExist(err) {
			http.Error(w, `{"error":"failed to remove discovery file"}`, http.StatusInternalServerError)
			return
		}
	}

	w.WriteHeader(http.StatusNoContent)
}

// processAlive reports whether a process with the given pid currently exists.
// signal 0 performs no delivery but runs the kernel's permission/existence
// check: nil means alive, ESRCH means gone.
func processAlive(pid int) bool {
	return syscall.Kill(pid, 0) == nil
}
```

## Notes & decisions carried from the spec

- **Session-scoped:** finished cards only for agents seen live this server run; a restart forgets them (still in Sessions list). Dismissal is durable (file deleted).
- **All controllable agents** included (pipeline-linked too); the pipeline enricher still annotates finished pipeline agents because stale agents are appended before `Enricher` runs.
- **Liveness via signal-0** (`syscall.Kill(pid,0)`); supported on macOS + Linux (Windows unsupported per project platform scope). PID-reuse is an accepted edge for a local single-user tool.
- **No DB table / no migration** — discovery files are the durable store; dismissal deletes them, which also fixes the pre-existing discovery-file leak.
