- **[security/xss]** G-C SEC-11 audit completed (PR security/sec11-vhtml-owasp) — only 3 `v-html` call sites exist (`AgentChatStream.vue` ×2, `RefinementChat.vue` ×1), all rendering user-controlled markdown via the SSOT `src/utils/markdown.ts` chokepoint which already pipes through DOMPurify. New `src/composables/useSafeHtml.ts` covers any future direct-HTML sinks. OWASP A03: all DB access is parameterized (incl. FTS5 search via quoted-token sanitizer in `server/internal/api/search/handler.go`). OWASP A07: JWT/OAuth-state cookies are `HttpOnly`, `Secure` (non-loopback), `SameSite=Strict|Lax`; `DASHBOARD_JWT_SECRET` requires ≥32 chars. OWASP A08: plugin loader `server/internal/plugin/registry.go` is wildcard — loads any directory containing a valid `plugin.json` with no enabled-list or hash pin; loopback-bind + plugin-id regex are the current safeguards. Documented in PR body; hardening deferred to a follow-up. `conf:high` (2026-05-24)
- **[roadmap-audit]** Greping the codebase for a feature's *spec-language* (e.g. `quota_period`, `QuotaChip`, `Identity*`) misses implementations that landed under different names. Before writing a spec against a "missing" roadmap item, also grep for the *behavior* (e.g. `/api/quota`, `useAgentIdentity`, `tokensUsed`) and inspect the components that would consume it (`App.vue` header, `AgentRow.vue`). G2 (IP-1) and G3 (CI-8) specs both proposed work already shipped — wasted spec/plan/agent time. `conf:med` (2026-05-22)
- **[frontend/lint]** `pnpm lint` runs ESLint repo-wide and is **chronically red on toml/yaml config files** (antfu config's `toml/*` + `yaml/*` plugins). That noise masks real lint errors in changed source files — implementers ran `pnpm lint`, saw failures, assumed all were pre-existing, and committed lint-dirty `.vue`/`.ts`. Always lint scoped to changed paths: `pnpm exec eslint <paths>`. `conf:high` (2026-05-30)
- **[frontend/vue]** The ESLint config enforces **camelCase custom event names** (`vue/custom-event-name-casing`). Kebab-case emits (`'open-sessions'`) fail lint; declare/emit `openSessions` instead. Template listeners may stay kebab (`@open-sessions`) — Vue normalizes them. The rule flags the `emit()`/`$emit()` call + `defineEmits` key, not the listener attribute. `update:xxx` v-model events are exempt when already camelCase. `conf:high` (2026-05-30)
- **[frontend/architecture]** Layout redesign (Plan 1) shipped a calm app-shell on branch `feat/layout-redesign`: `src/components/shell/` (AppShell, AppSidebar, NavItem, SidebarFooter, AppTopbar, AppStatusBar, DashboardToolbar, LivePulse, SkeletonCard, ChannelScriptCallout) + composables `useViewState`/`useSidebar`/`useStatusBar` + `utils/navConfig.ts`. The old `viewMode` string split into `activeView`+`dashboardLayout` (legacy `agent-view-mode` localStorage key auto-migrated). `SystemMetricsPanel.vue` + `ResourceBar.vue` deleted as duplicates (metrics now in AppStatusBar). Calm palette + indigo `--accent` token in `main.css` — every component reads tokens so the palette is a one-file lever. Plans 2-4 (per-component restyle fan-out, TaskModal decomposition, D3 palette + full blue→accent sweep) still pending. Spec: `docs/superpowers/specs/2026-05-30-layout-redesign-design.md`. `conf:high` (2026-05-30)
